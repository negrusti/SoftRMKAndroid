# Privacy Policy

This privacy policy applies to `SoftRMK`.

## Developer

SoftRMK is an unofficial independent project and is not made, endorsed, sponsored, approved, or supported by Raymarine.

Project source and issue tracker:
- [https://github.com/negrusti/SoftRMK](https://github.com/negrusti/SoftRMK)

Privacy contact:
- Use the repository issues page or the contact information published in the Google Play listing.

## Summary

SoftRMK is a local-network remote control app for compatible marine displays.

The app does not require account creation and does not use advertising SDKs or analytics SDKs.

## Data the App Uses

SoftRMK uses the following information to function:

- Local network connectivity state
- Wi-Fi interface state
- Multicast discovery traffic on the local network
- Compatible display identifiers and network endpoints discovered on the local network
- The selected paired display identifier
- A sender identifier stored locally for pairing/control compatibility

## What the App Stores

SoftRMK stores a small amount of app state locally on the device:

- remembered paired target identifiers
- remembered target names
- remembered broker/network endpoints
- remembered sender MAC or generated fallback sender identifier
- whether the startup notice has already been shown

This information is stored locally in the app’s private storage on the device.

## What the App Sends

SoftRMK sends control and pairing messages over the local network to compatible displays or their associated local broker service.

These messages may include:

- key press and key repeat commands
- rotary control commands
- pairing confirmation messages
- sender identifier values required by the device protocol

The app is intended to communicate only with compatible devices on the user’s local network.

## Data Sharing

SoftRMK does not sell user data.

SoftRMK does not share user data with advertising providers, analytics providers, or unrelated third parties.

Network traffic generated by the app is sent only as part of the app’s core functionality to compatible devices or services on the local network selected or discovered by the user.

## Data Retention and Deletion

Locally stored app data remains on the device until:

- the user clears app data
- the user uninstalls the app
- the app overwrites older remembered values with newer ones

Because the app does not use user accounts, there is no account-deletion workflow.

## Security

SoftRMK stores app state in the app’s private storage sandbox provided by Android.

The app communicates over the local network as required by the target device protocol. Users should use trusted local networks and compatible equipment they control or are authorized to access.

## Children

SoftRMK is not designed for children.

## Changes

This privacy policy may be updated as the app changes. The latest version should be published with the app source repository and the Google Play listing.
